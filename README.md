# منيو أماسينا الرقمي — دليل الاستعمال

صفحة واحدة ثابتة (HTML + CSS + JS)، بدون أي اشتراك مدفوع وبدون برامج بناء.
الملفات:

| الملف | شو فيه |
|---|---|
| `index.html` | هيكل الصفحة |
| `styles.css` | التصميم |
| `app.js` | التشغيل (اللغة، الأسعار) |
| `menu-data.js` | **كل النصوص والأسعار** — هذا الملف الوحيد اللي بتعدّلوه |
| `assets/` | الصور واللوغو |

---

## 1. تعديل الأسعار

1. افتحوا `menu-data.js` بأي محرّر نصوص (مثلًا TextEdit على الماك بوضع "نص عادي"، أو Notepad على ويندوز، أو VS Code).
2. ابحثوا عن اسم الطبق (Cmd+F / Ctrl+F)، مثلًا `أنتريكوت`.
3. بدّلوا كلمة `null` بالرقم، **بدون** علامة ₪ وبدون علامات تنصيص:

طبق بسعر واحد:
```js
"price": null,      ←  قبل
"price": 85,        ←  بعد
```

طبق بالوزن (لحوم وأسماك) — سعر لكل وزن:
```js
"prices": { "250": null, "330": null },     ←  قبل
"prices": { "250": 95, "330": 120 },        ←  بعد
```

4. احفظوا الملف وارفعوه من جديد (البند 2).

ملاحظات مهمة:
- لا تمسحوا الفواصل `,` ولا علامات التنصيص `"`. إذا الصفحة طلعت فاضية بعد التعديل، غالبًا انمسحت فاصلة.
- طالما السعر `null` الضيف بيشوف بس "اسألوا النادل عن الأسعار" تحت عنوان القسم، وما بيظهر أي سعر وهمي.
- أول ما تعبّوا سعر واحد بقسم اللحوم أو الأسماك، بيظهر لحاله عمودين للأسعار **250 غم** و **330 غم**.
- سعر السلطات (45 مع وجبة / 70 بدون) موجود تحت `"salad_offer"` ← `"options"`، وكمان مكتوب داخل `index.html` (الرقمين `45` و `70`) عشان يبينوا فورًا. إذا تغيّر السعر عدّلوه بالمكانين.
- لتغيير رابط الخريطة: عدّلوا `"maps_url"` بـ `menu-data.js` (حاليًا رابط بحث عام، حطّوا رابط Google Maps الدقيق للمطعم).

### إضافة صورة لطبق ما إله صورة
الصورة لازم تمرّ على نفس المعالجة عشان كل الصور تطلع بنفس الستايل:
1. حطّوا الصورة الأصلية بمجلد `src/` وزيدوها بملف `work/index.txt`.
2. زيدوا مدخل جديد تحت `"photos"` (انسخوا مدخل موجود مثل `"p22"` وغيّروا `src_id` والنص البديل).
3. شغّلوا `python3 tools/build_assets.py --no-video` من مجلد المشروع.
4. بالطبق نفسه غيّروا `"photo": null` لاسم المدخل الجديد، مثلًا `"photo": "p40"`. بتظهر صورة صغيرة جنب اسم الطبق.

## 2. نشر الموقع مجانًا على Netlify Drop

1. ادخلوا على **https://app.netlify.com/drop**
2. اعملوا حساب مجاني (بالإيميل أو بحساب GitHub). بدون حساب الموقع بينمسح بعد فترة قصيرة.
3. اسحبوا **مجلد `site` كله** (مش الملفات لحالها) وحطّوه بالمربّع.
4. بعد ثواني بيعطيكم رابط مثل `https://random-name-123.netlify.app`.
5. من **Site configuration ← Change site name** غيّروا الاسم لاسم واضح، مثلًا `amasina-menu` ← الرابط بيصير `https://amasina-menu.netlify.app`.

**تحديث الأسعار بعدين:** ادخلوا على الموقع بـ Netlify ← تبويب **Deploys** ← اسحبوا مجلد `site` المعدّل على المربّع اللي مكتوب فيه "Drag and drop your site output folder here". الرابط ما بيتغيّر، فالـ QR المطبوع بيضل شغّال.

بديل مجاني: GitHub Pages (ارفعوا محتوى `site/` لمستودع وفعّلوا Pages من الإعدادات).

## 3. عمل QR code للطاولات

1. افتحوا الرابط النهائي (مثلًا `https://amasina-menu.netlify.app`) بمتصفح **Google Chrome** على الكمبيوتر.
2. اكبسوا على زر المشاركة أو أيقونة QR بشريط العنوان (أو كليك يمين على الصفحة ← **Create QR code for this page**) ← **Download**.
3. اطبعوه **أسود على أبيض**، بحجم 3×3 سم على الأقل، ومعه سطر صغير: "امسحوا للمنيو / סרקו לתפריט".
4. جرّبوه بأكثر من تلفون (أندرويد وآيفون) قبل الطباعة الكبيرة.

نصيحة: لطاولات الزبائن اللي بيحكوا عبري ممكن تعملوا QR ثاني للرابط مع `?lang=he` بالآخر، مثل
`https://amasina-menu.netlify.app/?lang=he` — الصفحة بتفتح بالعبري مباشرة. الضيف بيقدر يبدّل اللغة بأي وقت من الزر فوق، والموقع بيتذكّر اختياره.

---

## 4. قبل طباعة الـ QR
- راجعوا الأسئلة المفتوحة تحت `"_owner_questions"` بآخر `menu-data.js` (أسماء غير مؤكدة، صور لازم تأكيد، أوزان السمك الكامل، الأسعار الناقصة، رابط الخريطة).
- افتحوا الموقع على التلفون بالعربي وبالعبري ومرّوا على كل الأقسام.
- تجربة محلية بدون إنترنت: افتحوا `index.html` مباشرة بالمتصفح (الخطوط بتحتاج إنترنت، الباقي بيشتغل).
